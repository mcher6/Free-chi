# ChiFree Radar MVP implementation plan

1. Define the canonical event schema, seeded demo data, explainable
   classifiers, scoring, deduplication, source configuration, and storage.
2. Implement three official Chicago source adapters, an allowlisted scraper,
   geocoding cache, health records, and validated public/admin APIs.
3. Build mobile-first map, list, and calendar views; event details; URL-backed
   filters; local saves; sharing; and calendar export.
4. Add the protected operations view, fixtures, unit/API/E2E coverage, Docker,
   scheduler assets, and operator documentation.
5. Run the complete verification chain, fix every failure, and publish to
   `mcher6/Free-chi`.
